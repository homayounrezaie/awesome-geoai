# Notebooks

One small runnable example per model.

## Categories

```text
vision/            # EO / remote-sensing vision foundation models
vision_language/   # remote-sensing VLMs and multimodal LLMs
generative/        # diffusion and image generation models
weather_climate/   # weather, climate, and atmosphere foundation models
hyperspectral/     # hyperspectral and spectral foundation models
vision_location/   # geolocation and location-embedding models
vision_audio/      # satellite-image/audio models
agentic_geoai/     # agents, copilots, and model-composition workflows
```

Notebook checklist:

- install/import required package
- load model or weights
- create or load one tiny sample input
- run inference or embedding extraction
- print output shape
- note CPU/GPU/RAM requirements
- note setup problems

Use this naming style:

```text
category/model_name_example.ipynb
```

Start with:

```text
vision/prithvi_eo_2_example.ipynb
vision/clay_example.ipynb
vision/terramind_example.ipynb
```
