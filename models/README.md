# Models

This folder contains the geospatial foundation model catalog in three formats.

## Files

```text
Geospatial-Foundation-Models.md     # human-readable catalog with notes and sources
geospatial_foundation_models.csv    # spreadsheet-friendly model table
geospatial_foundation_models.json   # machine-readable model registry
```

## Current Coverage

The CSV/JSON registry currently contains **216 model records** parsed from the comprehensive upstream RSFM index in the Markdown file.

Categories:

```text
vision
vision_language
generative
vision_location
vision_audio
```

## Important Note

The Markdown file is the source of richer notes and audit context. The CSV and JSON are for filtering, scripts, dashboards, and quick analysis.
